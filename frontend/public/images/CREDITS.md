# Illustrative photography credits

The photographs in this folder are **demonstration imagery**, not photographs of real
UrbanLedge projects or listings. They give the template a finished, art-directed look
until real project photography is available.

- Source: [Unsplash](https://unsplash.com) — free to use under the
  [Unsplash License](https://unsplash.com/license) (commercial use allowed, attribution
  appreciated but not required). Attribution is recorded here as good practice.
- To replace an image, drop your own file at the same path, keeping the file name and the `/images/...` path — every
  path is referenced from `backend/app/demo_content.py`, so no code change is needed.
- Recommended delivery: JPEG, 1600–2000 px on the long edge, quality ~70.
